#  Pulse – Fitness App Mood Board

##  Project Overview

**Pulse** is a fitness mobile app concept designed for **young adults aged 18–30**. This mood board presents the visual direction, color palette, and design inspiration used to create a modern, energetic, and motivating fitness experience. The app focuses on helping users stay active, healthy, and consistent in their fitness journey.

##  Color Palette

The mood board uses a bold and vibrant color scheme to create an energetic and modern look.

* **Primary:** `#FF5A1F` – Represents energy, motivation, and action.
* **Secondary:** `#1F3B73` – Creates trust, stability, and balance.
* **Accent:** `#B4FF3C` – Highlights important buttons and notifications.
* **Neutral Dark:** `#1A1A1A` – Used for text and contrast.

##  Visual Inspiration

The design is inspired by the following fitness elements:

* Group Workout & Energy
* Strength Training
* Fitness App Dashboard
* Wearable Heart Rate Monitoring
* Stretch & Recovery
* Healthy Nutrition

These visuals reflect an active, healthy, and motivating lifestyle.

##  Target Audience

* Young Adults (18–30 years)
* Fitness Beginners
* Gym Enthusiasts
* Health-Conscious Users

##  Design Goals

* Create a clean and modern interface.
* Inspire users to exercise regularly.
* Promote healthy living through fitness and nutrition.
* Ensure an engaging and user-friendly experience.

##  Motivation

> **"Stronger Every Day"**
> *Exercise not only changes your body, it changes your mind, your attitude, and your mood.*

##  Tools Used

* Figma
* Canva (for visual assets)
* GitHub

##  Conclusion

This mood board establishes the visual identity of the Pulse Fitness App. It combines energetic colors, inspiring fitness imagery, and a clean design style to create a motivating user experience. The mood board serves as the foundation for designing the app's UI and overall branding.
